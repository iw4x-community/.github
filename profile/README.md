# IW4x Community

This organization hosts projects developed independently by members of the IW4x community.

Repositories here are owned and maintained by their respective contributors. They are not maintained as part of the core IW4x project, which lives under [iw4x](https://github.com/iw4x).

If you maintain an IW4x-related project and would like a repository in this organization, reach us on Discord.
